# World Happiness Report Streamlit App

This project is a simple interactive Streamlit app that explores data from the 2019 World Happiness Report.

The app allows users to filter and compare countries based on different factors related to happiness and quality of life.

## Features

Users can filter the dataset by:

- Happiness Score
- GDP per Capita
- Country
- Social Support
- Healthy Life Expectancy
- Freedom to Make Life Choices

The app also displays:

- The number of countries currently shown
- The average happiness score of the filtered countries
- A table with the filtered results

## Dataset

The dataset contains information from the 2019 World Happiness Report.

Some of the variables included are:

- Overall Rank
- Country or Region
- Happiness Score
- GDP per Capita
- Social Support
- Healthy Life Expectancy
- Freedom to Make Life Choices
- Generosity
- Perceptions of Corruption

## App Design

Filters are located in the sidebar so users can easily explore different parts of the dataset.
